---------------------------------------------------PROJECT TERRARIUM----------------------------------------------------------

Terrarium is a Simple Project built with:
1. HTML - for the Structure of  Terrarium
2. CSS - for Design and Colors of Terrarium
3. JavaScript - for Live User Interactions in Web Page
   
Users can arrange their Own Beautiful Terrariums on this website by dragging and dropping the needed Plants.
Users can overlap Plants with each other.
Users can drag wherever they want within the VIEWPORT ( visible Area ).

Feature Used:
1. Color Change ANIMATION of Head from Black to Blue upon Mouse Hover
2. Smooth Drag and Drop TRANSITION (0.1s) of Plants inside Glass Pot.
